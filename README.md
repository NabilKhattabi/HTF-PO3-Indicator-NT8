# HTF_PO3 – Higher Timeframe Power of Three

**HTF_PO3** is a NinjaTrader 8 indicator that brings higher timeframe candles directly onto your current chart.

The idea is simple: keep the bigger picture visible without constantly switching between timeframes. HTF_PO3 displays higher timeframe candle structure in the right-side chart margin, along with key price levels and useful information about the developing candle.

Built with a focus on clean chart presentation, flexibility, and multi-timeframe analysis.

## Features

- **Multi-Timeframe Support:** Display Minute, Daily, or Weekly candles on any lower-timeframe chart.
- **Multiple HTF Candles:** Display up to 6 previous and developing higher timeframe candles.
- **Live Candle Updates:** Track the developing HTF candle as price changes in real time.
- **Open, High & Low Levels:** Display important price levels with optional horizontal lines.
- **Extended Levels:** Extend the latest candle's O/H/L levels back to where that candle started on the chart.
- **Price Labels:** Show the exact prices of the HTF High, Open, and Low.
- **NY Midnight Mode:** Build a custom daily candle starting at 00:00 New York time.
- **Live Countdown:** Track the remaining time until the current HTF candle closes.
- **Candle Range:** Display the current candle's range in points or ticks.
- **Flexible Positioning:** Choose between following the latest bar or fixing the candles to the right edge of the chart.
- **Custom Layout:** Adjust candle width, spacing, offset, and screen positioning.
- **Multiple Instances:** Run different HTF configurations simultaneously using independent display slots.
- **Custom Styling:** Configure bullish and bearish candle colors, wicks, outlines, lines, labels, and information box appearance.

## Installation

1. Download the latest release.
2. Open NinjaTrader 8.
3. Go to **Tools → Import → NinjaScript Add-On**.
4. Select the downloaded ZIP file.
5. Open a chart and add `HTF_PO3` from the Indicators menu.

**Note:** Increase the chart's Right Side Margin to give the HTF candles enough room to display properly.

## Intended Use

HTF_PO3 can be useful for traders working with Power of Three (PO3), ICT concepts, Smart Money Concepts (SMC), multi-timeframe analysis, and higher timeframe price delivery.

It is a chart visualization tool, not an automated trading system or signal generator.
